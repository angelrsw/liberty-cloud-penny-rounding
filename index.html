How it works

One-time setup. Zero cashier training.

A manager turns it on once. Every cash transaction from that moment forward rounds automatically. Your team doesn't have to remember anything new.

Create the Penny Round Up fee type

From the Liberty REACT POS main screen, tap More → Fee Types → Add. Name it "Penny Round Up", set GL Account Type to Other Income, Amount Kind to Variable Amount, leave Tax Type blank, and check Active.

The fee type holds the rounding adjustment so it lands on its own GL line.

Turn rounding on in Setup

From More → Setup → General, find the Cash Payment Rounding box. Set Rounding Kind to Nearest, Round To to 5, and Fee Type to Penny Round Up. Click OK. That's it.

Want 10¢ rounding instead? Change the Round To value. Want to turn it off? Set Rounding Kind to None.

Cashiers do… nothing different

The customer rings up. Cashier presses Cash. Liberty Cloud calculates the nearest 5¢ boundary, posts the Penny Round Up line, updates the total, and the drawer opens for the rounded amount. The receipt shows everything.

The math

Every possible cash total, rounded predictably.

Liberty Cloud uses banker-friendly "nearest" rounding. .X1 and .X2 round down. .X3 and .X4 round up. .X0 and .X5 don't move. Maximum adjustment per sale: ±2¢.

FAQ

Quick answers.

Does this affect credit, debit, or gift card sales?
No — only cash tenders are rounded. Card payments, gift cards, and store credit always settle to the exact cent.
What about split tender (cash + card) transactions?
The card portion is charged exactly. Rounding applies only to the remaining cash balance after the card payment posts.
Does rounding change how tax is calculated?
No. Tax is always calculated on the original item prices. The rounding adjustment is a separate, non-taxable line item.
Why is it called "Penny Round Up" if it can also round down?
The fee type name is user-defined — you can rename it whatever you want. The same fee type handles both directions, posting positive or negative adjustments as needed.
Can I round to a 10¢ increment instead of 5¢?
Yes. Change the Round To value in Setup → General from 5 to 10. The same fee type works regardless of the increment.
Is this available on Liberty Desktop?
No — Penny Rounding is a Liberty Cloud-only feature, alongside continuous updates, web-based access, and the ongoing roadmap of new capabilities. Desktop customers can migrate at any time.
How do I turn it off?
Go to More → Setup → General, set Rounding Kind back to None, click OK. Cash transactions immediately return to exact-cent amounts.
Will customers see the rounding on their receipt?
Yes. The Penny Round Up line item appears on screen during the sale and prints on the customer's receipt. Full transparency, no surprises.
